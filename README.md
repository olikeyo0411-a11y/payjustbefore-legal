# 결제직전 (payjustbefore) — 소개 · 약관 페이지

안드로이드 앱 **결제직전**의 서비스 소개와 법적 고지 문서를 호스팅하는 저장소입니다.

## 페이지

| 파일 | 내용 | 배포 주소 |
|---|---|---|
| `index.html` | 서비스 소개 (랜딩) | `/` |
| `privacy.html` | 개인정보처리방침 | `/privacy.html` |
| `terms.html` | 이용약관 | `/terms.html` |
| `style.css` | 공통 스타일 (다크모드 지원) | — |

## 배포

GitHub Pages — Settings → Pages → Deploy from a branch → `main` / `(root)`

배포 주소: `https://olikeyo0411-a11y.github.io/payjustbefore-legal/`

이 주소는 구글 플레이 등록(개인정보처리방침 URL)과 제휴 프로그램 신청 시 제출하는 웹사이트 URL로 사용합니다.

## 문서 수정 시 주의

- 앱이 실제로 수집·처리하는 항목이 바뀌면 `privacy.html`을 반드시 함께 고칩니다.
  (구글 플레이의 데이터 보안 신고 내용과 불일치하면 심사에서 문제가 됩니다.)
- 제휴 링크를 도입하면 `terms.html`에 제휴 수익 고지를, `privacy.html`에 클릭·전환 추적 고지를 추가해야 합니다.
- 내용을 바꾸면 각 문서 상단의 **시행일**과 **버전**을 갱신합니다.
